# Trip with Joanna

Kasper 與 Joanna 的旅行回憶：澳洲（墨爾本・雪梨）、沖繩、名古屋，一天一頁。

網站：https://kasperchengh.github.io/trip-with-joanna/

## 新增照片

1. 把照片放進對應的日期資料夾，例如 `Pictures/Okinawa/Day1`、`Pictures/Nagoya/Day3`。
2. 行程截圖或 PDF 放進 `Pictures/<旅程>/Schedule`。
3. Commit 並 push，照片就會自動出現在網站上（依檔名排序）。

同一個地點最多放 3 張風景或美食照片，人物照不限；不要放機票或訂位截圖。
